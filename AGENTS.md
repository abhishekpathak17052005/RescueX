# Rescue-X-AI Agent Instructions

This project is a native Android application built with Kotlin and Jetpack Compose.

## Architecture
- **UI**: Jetpack Compose
- **Pattern**: MVVM / Clean Architecture
- **Location**: Google Maps SDK / FusedLocationProvider
- **Voice**: Vapi AI

## Development Workflow
- Keep all development inside Android Studio.
- Use Gemini for UI building, debugging, and project iterations.
- Prioritize native Android capabilities.
