# Build RescueX — AI Emergency Assistance Mobile App

Build a complete mobile application called **RescueX**.

RescueX is an AI-powered emergency assistance and coordination app designed to help users quickly communicate an emergency, share their location, provide important emergency information, and connect with a responder workflow.

This must be a **real mobile application**, not a responsive website.

The app should feel like a polished startup product and should be suitable for a hackathon demo and future production development.

---

## 1. Technology Stack

### Mobile App

Use:

* React Native
* Expo
* TypeScript
* Expo Router
* NativeWind or Tailwind-style styling
* Expo Location
* Expo Notifications
* Expo SecureStore
* React Query/TanStack Query
* Zustand for lightweight state management
* Lucide icons

### Backend

Use:

* Node.js
* TypeScript
* Express.js
* PostgreSQL
* Prisma ORM
* JWT authentication
* Zod validation

### AI Voice

Use:

* Vapi AI

Keep Vapi credentials only on the backend.

### Maps

Use a map provider that works properly with React Native/Expo.

Create a map abstraction so the provider can be changed later.

# 7. Vapi AI Voice Assistant

Integrate Vapi AI.

The AI assistant is specifically designed for emergency information collection.

It should speak calmly and ask short questions.

Example:

"Tell me what happened."

"Are you currently safe?"

"Are you injured?"

"Where are you?"

"Is anyone else injured?"

"Do you need medical assistance?"

The AI should collect:

* Emergency type
* Severity
* Location
* Injuries
* Number of people involved
* Immediate danger
* Additional information

After the call, generate an incident summary.

Example:

"User reported a high-severity accident. One person may be injured. The user's current location has been shared."

Display the summary in the app.

# 29. Important Safety/Product Positioning

RescueX is an **AI-assisted emergency coordination application**.

Do not claim that RescueX itself is an official police, ambulance, fire, or government emergency service.

Do not automatically contact real emergency services during development.

For the MVP, use the RescueX responder workflow and demo integrations.

Any real emergency-service integration should only be added through appropriate authorized partnerships and APIs.
